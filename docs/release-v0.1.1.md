# Neko Break v0.1.1

这是 Neko Break 第一个面向公开下载整理的正式版本。

## 下载

- macOS Apple Silicon: `Neko Break_0.1.1_aarch64.dmg`
- Windows x64: `Neko Break_0.1.1_x64-setup.exe`

## 主要功能

- 固定间隔休息提醒
- 休息时长与工作间隔设置
- 陪伴时间、免打扰时间、今日暂停
- 休息记录、真实休息时长、提前结束/延后统计
- 透明小猫素材休息弹窗
- 场景库、场景导入、场景编辑
- 支持作者与素材共创社群入口

## 素材格式

- macOS 推荐使用带 Alpha 通道的 MOV
- Windows 推荐使用带 Alpha 通道的 WebM
- 普通视频适合全屏休息场景，不适合透明悬浮桌面效果

## 已知限制

- 当前安装包暂未代码签名
- Windows 当前提供 NSIS `.exe` 安装包，未提供 `.msi`
- Windows 托盘不支持像 macOS 菜单栏一样直接显示长文本状态，只能通过托盘提示和菜单显示
- 素材版权和社群素材分发仍在持续整理
