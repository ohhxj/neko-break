# Neko Break 项目管理说明

这个项目采用“安装包公开下载 + 代码半开源”的方式管理。

## 公开到 GitHub 的内容

- 项目介绍、安装说明和素材格式说明
- macOS / Windows 正式安装包
- 可复现的核心提醒逻辑、界面代码和基础构建配置
- Bug、功能建议、兼容性问题和路线图
- 面向用户的文档和设计规范摘要

## 不建议公开或不放进 Issue 的内容

- 支付、社群、增长转化的具体数据
- 原始设计提示词、未整理的 Image2 设计探索稿
- 未发布素材包、付费素材或社群专属素材
- 签名证书、构建密钥、私有账号配置
- 未来商业化方案、素材分发策略、桌宠生态的完整实现细节

## 建议公开 Issue

这些问题适合放到 GitHub Issues，方便用户反馈和协作：

1. Windows 透明 WebM 素材兼容性验证
2. macOS 未签名安装包首次打开提示说明
3. 素材导入失败时的错误提示优化
4. 休息卡片缩小 / 展开状态的交互打磨
5. 场景库列表滚动与底部按钮遮挡问题回归验证
6. 菜单栏 / 托盘状态文案统一
7. 休息文案库扩展：早中晚、喝水、护眼、肩颈活动
8. 素材格式转换指南：MOV Alpha 到 WebM Alpha
9. Windows 打包流程文档完善
10. 多类型陪伴场景：猫、狗、恋人、偶像、其他角色

## 暂不公开 Issue

这些内容建议先保留在内部需求管理里：

1. 社群转化路径和二维码展示策略
2. 赞赏入口样式和支付二维码替换
3. 桌宠配套能力的完整产品方案
4. 素材共创、素材分发、素材版权策略
5. 商业授权和二次分发策略

## 标签建议

- `bug`：明确可复现的问题
- `enhancement`：功能增强
- `design`：视觉、交互、布局
- `media`：素材、透明视频、封面提取
- `windows`：Windows 专属问题
- `macos`：macOS 专属问题
- `docs`：文档与说明
- `roadmap`：路线规划
- `private-backlog`：只做占位，不写敏感细节

## Release 规则

- GitHub Release 只上传正式安装包，不提交到 Git。
- 每个 Release 需要写清楚：
  - 支持平台
  - 素材格式限制
  - 是否签名
  - 已知问题
  - 从上一版升级是否会保留本地数据

## 当前 v0.1.1 发布重点

- macOS Apple Silicon 正式 DMG
- Windows x64 NSIS 安装包
- 透明素材导入和场景库
- 休息记录与陪伴时间
- 半开源许可和项目说明
