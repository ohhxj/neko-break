# Neko Break 字体规范

## 字体与基础规则

- 中文与正文：`-apple-system`, `SF Pro Text`, `PingFang SC`。
- 品牌、倒计时和大数字：`SF Pro Display`, `PingFang SC`。
- 页面不使用负字距，默认字距为 `0`。
- 标题行高 `1.25`，控件行高 `1.3`，正文行高 `1.45`。
- 同一语义必须使用同一个 CSS 变量，不新增临时的 `9px`、`13px` 等字号。

## 字号等级

| 语义 | 变量 | 字号 | 推荐字重 |
| --- | --- | ---: | ---: |
| 倒计时 | `--type-countdown` | 58px | 800 |
| 统计数字 | `--type-stat` | 34px | 800 |
| 品牌名称 | `--type-brand` | 22px | 800 |
| 弹窗标题 | `--type-modal-title` | 20px | 800 |
| 模块标题 | `--type-section-title` | 16px | 700 |
| 主要按钮 | `--type-button-primary` | 16px | 700 |
| 输入内容 | `--type-control` | 14px | 700 |
| 字段标题 | `--type-label` | 13px | 600-700 |
| 普通正文 | `--type-body` | 12px | 400-600 |
| 辅助说明 | `--type-caption` | 11px | 400-600 |
| 微型信息 | `--type-micro` | 10px | 400-600 |

## 模块映射

- 顶部：品牌使用品牌名称；心情文案与启用状态使用字段标题；主按钮使用主要按钮。
- 今日节奏：模块名使用模块标题；倒计时使用倒计时；间隔数字使用统计数字。
- 提醒规则：项目名使用字段标题；数值输入使用输入内容；时间按钮使用辅助说明。
- 今日记录：指标名、记录行使用辅助说明；指标数值使用字段标题；奖励文案使用微型信息。
- 实时预览：模块名使用模块标题；场景名使用字段标题；场景类型使用辅助说明。
- 场景库：分组标题与选择项使用字段标题；数量、卡片名和辅助状态使用辅助说明。
- 底栏：当前配置与版本使用微型信息；配置名称使用字段标题；说明使用辅助说明。
- 弹窗：标题使用弹窗标题；分区使用模块标题；字段与操作使用字段标题；说明使用正文或辅助说明。
