## 后续工作规则

- 新增需求：优先创建飞书多维表格记录。
- 独立 PRD：为需要展开说明的需求创建飞书 PRD 文档，并把链接回填到多维表格。
- 更新需求：优先更新飞书多维表格中的状态、优先级、负责人、排期、验收标准和关联链接。
- 更新 PRD：优先更新对应飞书 PRD 文档中的背景、目标、场景、范围、非目标、交互/技术注意点和验收标准。
- 本地文档：只维护流程说明和历史迁移记录，不作为新增需求或 PRD 的默认落点。
- 冲突处理：本地文档与飞书不一致时，以飞书为准。
- 接口优先：后续协助管理需求时，优先尝试使用飞书开放平台接口读取和写入数据。
