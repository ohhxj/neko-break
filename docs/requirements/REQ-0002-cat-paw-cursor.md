# REQ-0002：页面内可爱猫爪鼠标样式

## 背景

Neko Break 的产品气质是轻松、可爱、陪伴感强。页面内鼠标样式如果使用系统默认指针，会削弱应用的品牌记忆点。用户希望把应用内鼠标优化为可爱的小猫爪，并且默认状态、点击状态和点击过程中的过渡帧都要有差异。

## 目标

让用户在应用窗口内移动和点击时感受到一致的猫爪品牌细节，同时保持点击、拖拽、表单输入等基础操作清晰可用。

## 用户场景

- 作为用户，我在 Neko Break 页面内移动鼠标时，希望看到默认猫爪指针，而不是普通系统指针。
- 作为用户，我点击按钮、卡片或设置项时，希望猫爪有明显的点击状态反馈。
- 作为用户，我按下鼠标到松开鼠标的过程中，希望状态变化自然，不是生硬地瞬间切换。

## 功能范围

- 页面内默认鼠标指针替换为猫爪样式。
- 鼠标按下时切换为点击猫爪样式。
- 默认态到点击态之间需要支持过渡帧或等效过渡表现。
- 明确猫爪指针的生效范围：优先限定在应用窗口内部。
- 为可点击元素、普通区域、输入区域准备可用性规则。
- 提供基础降级方案，避免素材加载失败时影响操作。

## 非目标

- 不改变 macOS 系统全局鼠标样式。
- 不要求一次性覆盖所有拖拽、缩放、文本选择等系统指针形态。
- 不要求本需求直接产出最终插画资产；资产可以作为实现前置任务。

## 交互注意点

猫爪样式需要足够可爱，但不能影响定位精度。点击热区应该与视觉尖点或爪心位置一致，避免用户误以为点击位置偏移。

输入框、文本选择、窗口缩放等场景可能仍需要保留系统语义指针，避免可爱细节牺牲可用性。

“过度帧”在文档中统一表述为“过渡帧”。如果技术上无法使用 CSS cursor 原生动画，可以用短暂的点击帧切换、跟随鼠标的自定义元素，或其他实现方式达到同等过渡效果。

## 技术注意点

CSS `cursor` 通常适合静态图片，不一定能稳定播放连续帧动画。实现前需要确认采用静态 cursor 切换、APNG/GIF cursor、还是 DOM 跟随层模拟指针。

如果使用 DOM 跟随层，需要重点验证性能、延迟、窗口边缘表现、点击穿透、缩放比例和高 DPI 显示。

如果项目中已有猫爪资源，应先评估其尺寸、热点、状态数量和风格一致性，再决定是否复用或重绘。

## 验收标准

- 假设用户在应用主窗口内移动鼠标，当鼠标处于普通区域时，应该显示默认猫爪样式。
- 假设用户按下鼠标，当点击状态触发时，应该显示区别于默认态的点击猫爪样式。
- 假设用户从默认态进入点击态，当状态切换发生时，应该能看到过渡帧或等效的自然过渡表现。
- 假设用户进入输入框或文本选择场景，当猫爪样式会影响操作理解时，应该保留或降级为合适的系统语义指针。
- 假设猫爪素材加载失败，当用户继续操作应用时，鼠标仍然可见且可用。
