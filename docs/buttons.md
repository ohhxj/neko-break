# Neko Break 按钮规范

统一使用 `src/components/Button.tsx`，不要在业务模块里单独设置按钮高度、圆角和横向内边距。

## 尺寸

| 尺寸 | 高度 | 圆角 | 横向内边距 | 使用场景 |
| --- | ---: | ---: | ---: | --- |
| `sm` | 32px | 8px | 12px | 表格、卡片内的紧凑操作 |
| `md` | 40px | 10px | 16px | 弹窗与普通操作 |
| `lg` | 44px | 12px | 18px | 页面主要操作与底部操作组 |

同一个按钮组必须使用同一尺寸。图标按钮保持正方形，宽高等于对应尺寸。

## 类型

- `primary`：绿色正向操作，例如恢复提醒、确认启用。
- `accent`：紫色关键操作，例如立即休息、保存设置。
- `secondary`：白底描边次操作，例如今日暂停、支持作者、测试弹窗、取消。
- `warning`：橙色描边提醒操作，例如暂停今日提醒、延后一次。
- `ghost`：无边框低优先级操作。
- `danger`：删除等危险操作。

颜色表达状态而不是按钮大小：紫色用于品牌关键动作，绿色用于启用、恢复与完成，橙色用于延后和警告。暂停操作保持中性，不使用绿色或橙色实心按钮。

## 调用

```tsx
<Button variant="accent" size="lg" icon={<Save aria-hidden="true" />}>
  保存设置
</Button>
```

按钮文字只使用组件内置字号与字重。已有 Lucide 图标时不使用文本符号代替图标。
